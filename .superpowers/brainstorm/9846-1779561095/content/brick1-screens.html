Already installed as a plugin. Uses app/app/ directory for screens. Gives us URL-based navigation, deep linking, and layout routes for the tab structure. Recommended — it's already in your dependencies.

Data Flow

Sign-up creates everything
signUp(email, password, name)
  → Supabase Auth creates auth user
  → INSERT household (auto-named)
  → INSERT user (linked to household)
  → SELECT seed_default_locations(household_id)
  → 3 locations created: Fridge, Freezer, Cupboard
Receipt scan pipeline
1. Camera/gallery → image URI
2. uploadAndCreateReceipt() → receipt record (pending)
3. parseReceipt() → Edge Function → Claude Vision
4. User reviews parsed items (inline edit)
5. confirmReceipt() → resolveProduct() per item → inventory
